# AI Usage

Generative AI was used as an assistive tool during this project for:

- Explaining RISC-V, quantization, and custom ISA concepts.
- Assisting with Python and C code drafting and debugging.
- Reviewing `Xqmac8` and `Xrequant` instruction semantics.
- Helping organize Spike profiling results and calculate derived metrics.
- Assisting with documentation, report structure, and technical wording.
- Helping troubleshoot Git, build, linker, and profiling issues.

All important AI-assisted outputs were manually verified.

- Code was compiled and executed in the actual project environment.
- Custom instructions were verified with directed and randomized tests.
- Numerical results were obtained from Python references and Spike execution.
- Performance numbers were derived from actual profiling results rather than generated by AI.
- Final correctness and experimental conclusions remain the responsibility of the project author.
